# 📊 Análise de Fatores Salariais na Área de Dados

> Projeto de Introdução à Regressão Linear aplicada ao mercado de trabalho em dados

## 📌 Sobre o Projeto

Este projeto tem como objetivo analisar os fatores que influenciam os salários na área de dados, utilizando regressão linear para prever remunerações com base em características dos profissionais.

A partir de variáveis como **idade**, **experiência profissional**, **localização** e outros aspectos relevantes, o projeto busca identificar padrões e relações que impactam diretamente a remuneração — e compreender quais fatores têm maior peso nas desigualdades salariais do setor.

---

## 🎯 Objetivos

- Aplicar o modelo de **regressão linear** para previsão de salários
- Identificar as variáveis com maior influência na remuneração
- Realizar análise exploratória dos dados (EDA)
- Extrair insights relevantes para o mercado de trabalho em dados

---

## 🗂️ Etapas do Projeto

1. **Coleta e entendimento dos dados**
2. **Limpeza e tratamento dos dados**
3. **Análise exploratória (EDA)**
4. **Construção do modelo de regressão linear**
5. **Avaliação e interpretação dos resultados**

---
